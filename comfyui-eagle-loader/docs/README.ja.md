## どのノードを使えばよいか

まず画像を読み込みたい場合は `Eagle Image Browser` を使います。  
ComfyUI で作った画像を Eagle に保存したい場合は `Eagle Quick Send to Eagle` を使います。  
既存の Eagle item のタグや評価を変更したい場合は `Eagle Quick Update Item` を使います。

詳細版のノードは、簡易版では足りないときに使うものです。
