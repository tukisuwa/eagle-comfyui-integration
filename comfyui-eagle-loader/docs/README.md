## Which Node Should I Use?

Use `Eagle Image Browser` when you want to find and load images from Eagle.  
Use `Eagle Quick Send to Eagle` when you want to save generated ComfyUI images into Eagle.  
Use `Eagle Quick Update Item` when you want to edit tags, rating, annotation, folder, or trash state for an existing Eagle item.

The full nodes are still available when the quick nodes do not expose enough settings.
